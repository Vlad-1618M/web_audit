Web Audit for Mac — Swift UI mockups

Five screens for a one-window owner app: URL in, plain-English progress, report opens in the browser. Design reference only — not shipped Swift code yet.

README · user-flow.md (full diagrams)

01 · Ready

Idle state — paste URL, single primary action.

02 · Scanning

Scrolling live log — same lines as webaudit -v stdout.

03 · Report ready

Open in browser · Download HTML · Share. muzar.io + GitHub links in footer.

04 · Error

Invalid URL or unreachable site — no jargon.

05 · Help & Advanced

“What is this?” sheet; Advanced collapsed by default in prod.

User flow — happy path

Site owner launches app → scans permitted URL → opens HTML report → optional share with developer.

flowchart TD
  A([Launch app]) --> B[Enter website URL]
  B --> C{Valid https?}
  C -->|No| D[Error: paste full address]
  D --> B
  C -->|Yes| E[Scanning: live log scrolls with stdout]
  E --> F{Success?}
  F -->|No| G[Help: site down or blocked]
  G --> B
  F -->|Yes| H[Report ready]
  H --> I[Open in browser]
  H --> J[Download HTML]
  H --> K[Scan another site]
  I --> L([Owner HTML report])
