Web Audit for Mac — install (self-contained, unsigned alpha)
============================================================

You do NOT need Docker. You do NOT need to install Python on your Mac.
The scan engine is already inside Web Audit.app.


SYSTEM REQUIREMENTS
-------------------
• macOS 13 (Ventura), 14 (Sonoma), or 15 (Sequoia) — Intel or Apple Silicon
• Internet access (the app checks public websites over the network)
• About 400 MB free disk space (app + bundled scan engine + browser for JS scans)


INSTALL
-------
1. Open this disk image (you are reading this from it).
2. Drag "Web Audit.app" onto the "Applications" folder shortcut.
3. Eject the disk image.


FIRST LAUNCH (unsigned build — read this)
-----------------------------------------
Downloads from the web are often blocked until you approve the app once.
You may see "damaged", "can't be opened", or a security warning.

Recommended steps (easiest — one double-click script):

  1. After dragging Web Audit to Applications, double-click
     "Clear-Quarantine.command" on this disk image.
     (Terminal opens, runs one safe command, then tells you what to do next.)

  2. When Terminal says "OK: cleared quarantine on Web Audit", press Return
     to close Terminal.

  3. Open Applications and double-click Web Audit.

  4. If macOS still warns you once:
       Right-click Web Audit → Open → click Open.
     After that, double-click works normally.

Without the script (manual):

  Applications → right-click "Web Audit" → Open → Open

Advanced (paste in Terminal yourself):

  xattr -cr "/Applications/Web Audit.app" && echo "OK: cleared quarantine on Web Audit"

Then open Web Audit from Applications as above.


SCAN A WEBSITE
--------------
1. Open Web Audit from Applications.
2. Paste your site URL (must start with https://).
3. Tap "Scan my website".
4. When finished, open the report or find files under:

     ~/Documents/WebAudit/


IF SOMETHING IS WRONG (simple checklist)
----------------------------------------
Work through these in order. Most problems are fixed by step 1 or 2.

  1. Quit Web Audit completely (Web Audit menu → Quit), then open it again.

  2. "Damaged" or won't open after download?
       Run Clear-Quarantine.command again (or the xattr line in FIRST LAUNCH).

  3. Check the URL:
       • Must start with https://  (not http:// alone)
       • Example: https://example.com

  4. Check your internet connection (open any website in Safari).

  5. Check free disk space (Apple menu → About This Mac → Storage).

  6. Reinstall the app:
       • Drag Web Audit.app from Applications to Trash
       • Open this disk image again
       • Drag Web Audit.app to Applications (replace if asked)
       • Double-click Clear-Quarantine.command, then open the app

  7. Still stuck? In the app, tap "Show log in Finder" on the error screen and
     send that file to the developer (it includes the URL, date, and scan output).
     Logs are also saved under ~/Documents/WebAudit/Logs/

  8. Contact support with that log file if the problem persists
     (links at the bottom of this file).


ABOUT PYTHON (you usually can ignore this)
------------------------------------------
Web Audit ships with its own Python scan engine inside the app bundle.
You do NOT need to download or install Python from python.org for normal use.

  • Do NOT install Docker for this app.
  • Clear-Quarantine.command is the only Terminal helper we ship for early adopters.

If support asks you to verify the bundled engine (advanced), in Terminal run:

  "/Applications/Web Audit.app/Contents/Resources/Engine/bin/webaudit" --version

You should see a line like: webaudit 2.1.0b4 (bundled engine)
(Use --help instead of --version on very old builds.)

If both --version and --help fail after a fresh reinstall, the app bundle may be
incomplete — download the .dmg again.

Official Python documentation (only if you are curious — not required):
  • Downloads:  https://www.python.org/downloads/
  • macOS help: https://docs.python.org/3/using/mac.html


UNINSTALL
---------
Drag "Web Audit.app" from Applications to Trash.

Optional: delete old reports at ~/Documents/WebAudit/


REINSTALL
---------
Download the same .dmg again, drag the app to Applications, replace if asked,
then run Clear-Quarantine.command once before opening.
