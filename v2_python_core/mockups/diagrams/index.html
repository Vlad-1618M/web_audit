6. Framework profile resolution

WordPress detected → wordpress profile; else generic

sequenceDiagram
  participant U as User
  participant O as Orchestrator
  participant D as Detect
  participant P as Profile
  participant C as Collectors

  U->>O: webaudit scan URL
  O->>D: fingerprint site
  alt WP confidence ≥ 0.65
    D->>P: wordpress/extensions.yaml
  else Django / Laravel
    D->>P: django|laravel profile
  else unknown
    D->>P: generic/php.yaml
  end
  P->>O: merge site.extensions
  O->>C: enabled collectors
  C-->>U: reports + JSON
